Quick Start

Prerequisites

Before installing Zytra Terminal, ensure you have:

  • ✓ Linux system (Ubuntu 20.04+)
  • ✓ 64-bit processor
  • ✓ Required libraries installed

Installation Steps

Step 1: Install Dependencies

sudo apt-get install -y libkeybinder-3.0-dev libayatana-appindicator3-dev

Step 2: Download Latest Release

wget https://github.com/atrox39/zytra-terminal/releases/latest

Step 3: Extract and Run

tar xzf zytra-terminal-*.tar.gz && ./zytra-terminal/zytra_terminal

Keyboard Shortcuts

New Tab Ctrl+T
Close Tab Ctrl+W
Restore Tab Ctrl+Shift+T
Fullscreen F11
